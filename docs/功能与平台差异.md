## Core 模块与适配分支

本 fork 是基础设施 Core，包保持 `co.touchlab.stately`，基于 Touchlab Stately2.1.0，没有 Compose/Kuikly UI 模块。实际发布工程为 [stately-probe](../stately-probe/settings.gradle.kts)，仅包含以下3个 Core 模块；`deprecated` 隔离集合及其他上游变体不在发布范围。

| 模块 | 功能 / 传递关系 |
| --- | --- |
| `stately-strict` | 新内存模型下的旧 freeze/线程标注兼容辅助；并发模块传递引入 |
| `stately-concurrency` | AtomicInt/Long/Reference、ThreadLocalRef、ThreadRef、Lock/Synchronizable；依赖 strict |
| `stately-concurrent-collections` | ConcurrentMutableMap/List/Set 与受控视图、iterator、block；依赖 concurrency |

OpenHarmony 适配分支为 **codex/ohos-2.1.0**，默认 **main 是上游基线**。保留 `co.touchlab` KLIB 身份，Maven 使用 fork 组名；不能因上游 main 更新就声称新内容已适配/发布。

| 五种入口 | 实际映射 | UI/生命周期边界 |
| --- | --- | --- |
| CMP Android | 三个 Core 的 JVM 变体 | JVM 原子变量/ThreadLocal/ReentrantLock；不提供 Compose 状态适配 |
| CMP iOS | 三个 Core 的 Native/Apple 变体 | Native 原子变量/ThreadLocal/pthread；不提供 UI owner |
| Kuikly Android | 同 JVM Core | 宿主负责状态通知与资源生命周期 |
| Kuikly iOS | 同 Native/Apple Core | 同上，无专用 Kuikly 模块 |
| Kuikly OHOS | 同 Native Core；Lock 复用 Linux/POSIX 实现 | 宿主 OHOS 工具链，ArkTS 需已有 FFI；不提供现成桥 |

## 差异分类与集合合同

- **组件范围/不提供的入口**：本 fork 只提供实际3个并发 Core 模块，不提供 UI 状态转换、UI scope 或现成 ArkTS 桥；这些范围边界不代表待新增模块，不能照搬上游其他模块作为承诺。
- **OS/SDK 限制**：OHOS 使用 Kotlin2.2.21-1.0.0；Native 锁/线程局部行为依赖实际 SDK。最低 iOS/OHOS 设备兼容范围未独立验收。
- **宿主职责**：资源 owner、结束并发调用后 close、集合复合操作放 block，跨线程状态通知由宿主 UI 层负责。不得在 block 内等待另一个需要同锁的线程。
- **锁/结构修复**：嵌套 subList/iterator、Map keys/values/entries 沿同一 root；Entry key/value/setValue 都加根锁，equals/hash 遵守 key/value 合同。List/Set/Map/entries 结构 equals/hash 使用 own-lock snapshot 后在锁外比较；bulk 操作先在外部 Concurrent 输入的源锁下复制，再持目标锁，同根/self 保持原子语义，避免 A↔B 反序持锁。
- **block 修复与精简**：正常返回/抛错都 finally 撤回直接 wrapper，复用 list/set 的继承 delegate，去掉结束时分配空集合；block 提供的 List/Set/Map wrapper 也具有结构相等/hash。派生 iterator/subview/entry **不得逃逸 block**，本轮没有实现派生引用自动撤销。未增加可引发 self-reference 递归的容器 toString override。
- **未验收**：OHOS 集合行为运行、跨端长期线程竞争/ThreadLocal 隔离压力、真实 UI 业务负载；JVM 两线程回归不是完整压力验收。

## 验证结果与测试入口

**时点**：前轮代码复核运行 JVM6项、Simulator4项及 OHOS编译；本轮最终核对只加固 JVM 锁测试后重跑 JVM，生产源码不变。

| 覆盖 / 相对测试入口 | 实际执行与证据层级 | 待验收边界 |
| --- | --- | --- |
| [BlockLifetimeTest](../stately-concurrent-collections/src/commonTest/kotlin/co/touchlab/stately/collections/BlockLifetimeTest.kt) | 本轮JVM4项；复用前轮Simulator4项：结构equals/hash、block正常/异常撤回、self/同根bulk、嵌套视图 | 直接wrapper撤回；派生引用不允许逃逸，不是自动撤销 |
| [RootLockContractTest](../stately-concurrent-collections/src/jvmTest/kotlin/co/touchlab/stately/collections/RootLockContractTest.kt) | **本轮新跑** JVM2项：Entry key/value/setValue与嵌套iterator读写分别等待原root monitor；双向bulk barrier与worker错误回传 | JVM Synchronizable实际使用synchronized；没有把monitor断言套到Native锁或声称长期压力通过 |
| 平台接线 | 前轮 `stately-probe/:stately-concurrent-collections:compileKotlinOhosArm64`（含依赖strict/concurrency） | OHOS编译，未执行；Android采用JVM Core，没有Android设备测试 |

本轮 `stately-probe/:stately-concurrent-collections:jvmTest` 6项、前轮Simulator4项，均0失败/错误/跳过。临时review init限定上述文件，**不是完整上游测试集**。原锁测试将getter与setter串在一个worker且未回传断言，可能漏报裸读；现在分开观察明确root monitor等待，Future.get向测试线程传播异常。本轮隔离源码副本仅去掉Entry value getter锁，或仅制造worker断言错误，均出现预期红灯；原Worktree生产代码未改。正式tag的Koin消费者链接与Compose混用保留为历史事实，本轮未重新发布或远程消费。
